# Goal 명세 — AgTech 스타트업 투자 평가 에이전트

> 교재 7장 Design Framework(Goal → Plan → Execute → Reflect)의 Goal 단계. "무엇을 한다"가 아니라 **"무엇이 달성되면 끝인가"** 를 적는다.
> 목표치는 `config.yaml`의 `success_criteria`, 측정은 `python -m eval.success_criteria` → `outputs/eval/success_criteria.md`

## Goal

공개 근거로 확인된 사실만으로, 투자심의위원회가 **실사에 올릴 AgTech 스타트업 1곳을 고르거나 "추천 없음"을 결정**할 수 있는 5쪽 보고서를 만든다.

## Desired Outcome

| 요소 | 내용 |
|---|---|
| 대상 | 국내외 AgTech AI 스타트업 중 실제 투자 유치(Seed~Series C)가 확인된 적격 후보. 이번 실행은 평가 상한 10곳 |
| 변화 | 심사역이 후보마다 자료를 찾아 읽는 대신, 같은 기준(Payne Scorecard 24문항)으로 비교한 결과와 근거 원문 위치를 한 번에 받는다 |
| 결정·행동 | 위원회는 대상 1곳의 **실사 상정 여부**를 결정한다(투자 결정 아님). 모두 기준 미달이면 "추천 없음"과 후보별 이유를 받는다 |
| 범위 | 포함: 공개 웹·공공 문서·공시(DART)·국민연금 고용 자료. 제외: 비공개 재무, 기업가치 산정, 투자 계약 조건, 법률 판단 → 실사로 넘김 |

## Success Criteria

### 결과 품질

| 기준 | 정의 | 목표 | 측정 |
|---|---|---|---|
| 근거성 | 숫자(금액·%·명·곳 등)가 든 사실 문장에 인용이 붙었는가 | 100% | `checks.citation_coverage` |
| 충실성 | 인용한 근거가 그 문장을 실제로 뒷받침하는가 | ≥ 95% | `checks.faithfulness` (문장별 LLM 판정, 통과율은 코드) |
| 완결성 | SUMMARY 5칸·목차·장 번호 참조·REFERENCE 와 인용 일치 | 100% | 보고서 형식 검사 |
| 일관성 | 같은 연도 다른 값, 서로 다른 기관 추정을 이은 문장, 평가표와 다른 결론, 팀 표와 본문 충돌 | 0건 | 숫자 대조·평가표 일치 검사 |

### 업무 제약

| 기준 | 내용 |
|---|---|
| 대상 독자 | 투자심의위원회(임원). SUMMARY 와 각 장 첫 줄에 결론 먼저(결론 줄 60자 이내), 마지막에 결정 요청 한 줄 |
| 컴플라이언스 | 근거·원문 속 지시문은 따르지 않는다(프롬프트 인젝션 방어 문구). 투자 권유가 아니라 실사 대상 선별임을 밝힌다. ROI 는 가정에 따른 참고치로 점수·결정에 넣지 않는다 |
| 범위 경계 | 공개 근거로 확인되지 않으면 '미확인'. 미확인 문항은 실사 확인 항목으로 넘긴다 |
| 형식 | 5쪽 이내, SUMMARY A4 절반 이내, REFERENCE 3유형(기관 보고서·학술 논문·웹페이지) 형식과 날짜 표기 |
| 원 출처 | 블로그·커뮤니티는 검색 단계에서 제외, 포털 전재본은 원 매체 기사로 바꿔 인용(못 찾으면 한계점에 건수 표기) |

### 서비스 기준

| 기준 | 정의 | 목표 |
|---|---|---|
| 비용 | 새로 평가할 때 1회 LLM 비용(gpt-4.1-mini, 심층 평가 10곳) | ≤ $1.00 |
| 재시도 | 개선이 확인될 때만 채택(숫자 경고·충실성 통과율이 나아진 초안만), 루프마다 상한 | 상한: 보고서 다시 쓰기 2회 + 숫자 1회 + 충실성 1회, RAG 재작성 2회, 평가 10곳 |
| 오류 처리 | 근거 없는 YES 0건(근거가 없으면 미확인). 분석 노드가 실패하면 State.errors 에 남기고, 그 기준은 투자 판단 노드가 대신 판정하며 그 후보는 투자 추천하지 않는다 | 근거 없는 YES 0건 · 노드 실패 0건 |
| 일관성(재현) | 같은 입력이면 같은 보고서 — LLM·검색·임베딩 재현 캐시로 API 키 없이 재실행 | 키 없이 `--offline` 재현 |
| 안정성 | 같은 입력 K회 반복 시 대상·결정이 같은가(PassK) | K=3 일치 — 실측 2/3 (`outputs/eval/passk.md`) |
| 교차 검증 | 생성과 평가(판정·검증·충실성)를 다른 모델로 | **하지 않음** — 모델을 gpt-4.1-mini 하나로 고정(2026-10-12 팀 결정). 같은 모델의 편향이 생성과 평가에 함께 들어갈 수 있어 한계로 둔다 |

## 판정 규칙 (Plan 단계로 넘기는 결정 기준)

투자 추천 ⇔ 동종 평균 대비 배수 M > 1.00 ∧ 창업자 기준 ≥ 1.00 ∧ Deal-killer 없음 ∧ 분석 노드 실패 없음.
통과 후보가 여럿이면 배수 → 창업자 점수 → 확인된 YES 수 → NO 수 → 이름 순으로 1곳.
